# Koleksi Drama Korea Web App

Proyek aplikasi web CRUD (GET, POST, PUT, DELETE) bertema kumpulan Drama Korea menggunakan:
- **Back-End**: Node.js, Express, TypeScript (Arsitektur Modular: Controllers, Middleware, Routes)
- **Front-End**: HTML5, Pure CSS (Tanpa Framework), Vanilla JavaScript (`script.js`)

## Cara Menjalankan
1. Jalankan `npm install` di terminal.
2. Jalankan `npm run dev` untuk menyalakan server.
3. Buka `http://localhost:3000` di browser.
